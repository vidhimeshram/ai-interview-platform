# AI Interview Platform

An AI-powered mock interview platform where users practice interviews and get instant feedback.

## Features
- User registration and login (JWT authentication)
- AI-generated interview questions
- Answer evaluation and feedback
- Profile management

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **AI:** (OpenAI / Gemini, whichever you used)

## Setup

### Backend
cd backend
npm install
# create .env using .env.example
npm run dev
